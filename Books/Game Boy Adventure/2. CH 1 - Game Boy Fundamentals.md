
Game boy was also called the Dot Matric Game (DMG) as called internally by the Nintendo

three steps to running the program, we should convert the program into ROM

### Compilation Steps

#### Assembly Step

this converts the assembly code or the source code into the object file containing machine code
```
rgbasm -Werror -Weverything -o firstProg.o firstProg.rgbasm
```

#### Linkage Step

this step takes one or more of the object files, and then compiles into the single ROM

--dmg option diables the VRAM / WRAM bank switching, increases the memory available

--tiny disables the ROM switching, 
```
 rgblink --dmg --tiny -o sample.gb firstProg.o
```

#### Fixing

proper values inside from the header values, and ensures that the ROM is valid

--title-game sets the title of the game max 11 characters
--pad-values the unsused parts of the ROM are intiliazed with 0
--validate fixes the logos or the checksums


```
rgbfix --title game --pad-value 0 --validate sample.gb
```


This whole basic process of Assembly -> Linkage -> Fixing in this case can also be termed as compilation

#### Run the compiled file

```
 & 'C:\Code and Shit\bgbw64\bgb64.exe' --rom .\Practice\sample.gb --watch
```
